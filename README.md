# Fish Trade Dashboard

## รายละเอียดโครงงาน
โครงงานนี้เป็นการพัฒนา Dashboard สำหรับวิเคราะห์และแสดงข้อมูลการค้าปลา
โดยนำข้อมูลมาวิเคราะห์และนำเสนอในรูปแบบกราฟและ Dashboard

## เทคโนโลยีที่ใช้
- HTML
- CSS
- JavaScript
- D3.js

## ไฟล์ภายในโครงงาน
- index.html
- style.css
- app.js
- data.xlsx
- Analysis การวิเคราะห์ข้อมูล.pdf

## วัตถุประสงค์
1. เพื่อวิเคราะห์ข้อมูลการค้าปลา
2. เพื่อแสดงข้อมูลในรูปแบบ Dashboard
3. เพื่อช่วยให้สามารถมองเห็นข้อมูลและแนวโน้มได้ง่ายขึ้น
